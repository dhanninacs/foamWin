/ the port
A port, not a wrapper.

    

      

        
FoamWin is Foundation OpenFOAM 14, cross-compiled with MinGW-w64 GCC and given a Windows operating-system layer derived from blueCFD. The output is ordinary Windows executables and DLLs.

        
Case dictionaries, executable names, package filenames and the OpenFOAM namespace are untouched, so tutorials and scripts carry over.

/ workflow
Install to cavity in five steps.
Every step is exercised by the package's own smoke tests on a clean Windows machine.

    

      

        
        
        
        
        
      

      

        
Download
Take OF14-win-setup.exe for a guided install with shortcuts and an uninstaller, or the portable OF14-win.zip. Check both against SHA256SUMS.txt.


# verify the installer
Get-FileHash .\OF14-win-setup.exe `
  -Algorithm SHA256
# compare with SHA256SUMS.txt

      

      

        
Launch
Open the OpenFOAM 14 shortcut, or double-click of14-shell.bat. The launcher wires up binaries and DLLs, then drops you in your run directory.


# from the extracted package
. ./of14-shell.ps1 -Quiet
# everything is on PATH, as on Linux
blockMesh -help

      

      

        
Mesh
blockMesh for structured cores, snappyHexMesh for geometry, and cfMesh: cartesian, tet, poly and 2D meshers with boundary layers.


blockMesh
checkMesh
# or cfMesh
cartesianMesh

      

      

        
Solve
Legacy solvers such as icoFoam and the modern foamRun framework. Serial by default, or local parallel with optional Microsoft MPI.


icoFoam
# or the modular solver
foamRun
# full smoke test, 4 processes
./of14-smoke-test.ps1 -Processes 4

      

      

        
View
The smoke test writes cavity.foam. Open it in ParaView, or export with foamToVTK and post-process with foamPostProcess.


foamToVTK
# then open cavity.foam in ParaView

      

    

    
Paths containing spaces are handled by a temporary junction alias, so C:\Program Files\FoamWin and D:\my cases both work without renaming anything.

/ limits
What it won't do.

    
    
      
  • 64-bit Windows onlyDouble precision, 32-bit labels — the combination that was built and tested.
    • 
      
  • No bundled viewerInstall ParaView and open cavity.foam. VTK export is built in.
    • 
      
  • Runtime compilation needs setupFunction-object code compiled at run time wants an extra compiler configuration. Prebuilt libraries are unaffected.
    • 
      
  • Local parallel onlyMulti-host runs and performance scaling under MS-MPI have not been measured.
    • 
    

  






  

    
/ for builders
An engine with a socket.

    

      
A Windows host application does not have to speak Bash to drive OpenFOAM. of14-env.ps1 returns one JSON document containing:

      
schema versionflavourabsolute tool pathsprepared environmentlibrary namesMPI availabilitynormalised case directory

      
Run it as an argument list, parse the JSON, use the paths. It exits with status 2 and a diagnostic if a required tool is missing, so a host adapter fails loudly instead of silently solving nothing.
